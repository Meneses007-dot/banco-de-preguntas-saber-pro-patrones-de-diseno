# Banco de Preguntas Saber Pro - Patrones de Diseño

Proyecto de Ingeniería de Software II de la Universidad del Cauca para gestionar preguntas tipo Saber Pro aplicando patrones de diseño en Java.

## Requisitos

- JDK 17 o superior
- Maven 3.9 o superior

## Ejecutar pruebas

```bash
mvn test
```

## Patrones implementados

- Adapter
- Builder
- Decorator
- Facade
- State
- Template Method
